PYTHON CALCULATOR

Description

This is a simple calculator application built using Python. It allows users to perform basic mathematical operations through the terminal.

Features

- Addition
- Subtraction
- Multiplication
- Division
- Accepts user input
- Uses a loop to allow repeated calculations
- Allows the user to exit the calculator

Technologies Used

- Python

Requirements

- Python installed on your computer
- A code editor, such as Visual Studio Code

How to Run

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open the terminal.
4. Run the following command:

python calculator.py

Replace "calculator.py" with the actual name of your Python file if it is different.
